# Django E-commerce Website

A full-stack e-commerce web application developed using Django and Python.

## Technologies Used
- **Backend:** Python, Django
- **Frontend:** HTML, CSS, Bootstrap
- **Database:** PostgreSQL
- **Tools:** Git, GitHub, Docker

## Features
- Product listing and product detail pages
- Product categories and variants
- Product images and color selection
- Database integration
- Django administration panel

## Getting Started
Clone the repository and follow the installation instructions to run the project locally.
- docker compose build 
- docker compose up -d
- docker exec -it oms_web bash 
- python manage.py makemigrations
- python manage.py migrate
